Methodology

Data pipeline

How 13,026 articles were extracted, filtered, and structured for analysis

This corpus was assembled to study how Swiss German-language media covered AI — from early mentions in financial press to the ChatGPT explosion. The pipeline moves from a proprietary media archive through linguistic corpus tools to a structured CSV ready for analysis.

1
Source
Swissdox archive query
The Swissdox platform (UZH) provides licensed access to Swiss press archives. Queries are written in LCP (Linguistic Corpus Platform) syntax. Articles were matched by token form — searching for AI, IA, GenAI, LLM, Chatbot in any segment, with article-level metadata extracted.
# LCP Query — search AI-related forms in all segments Article a Segment@a s Token@s t1 OR form = "AI" form = "IA" form = "GenAI" form = "LLM" form = "Chatbot" byYear => analysis attributes a.head, a.subhead, a.pubdate, a.source, a.articleURL functions frequency

2
Export
Result processing & export
Query results arrive as TSV/JSON from the LCP API. The export processor notebook normalises encoding, deduplicates articles (same URL appearing across multiple token matches), and coerces date formats to ISO 8601.
# export_processor.ipynb import pandas as pd df = pd.read_csv('query_result.tsv', sep='\t') # Deduplicate on article URL (same article can match multiple tokens) df = df.drop_duplicates(subset=['articleURL']) # Normalise date column df['pubdate'] = pd.to_datetime(df['pubdate'], errors='coerce') df = df.dropna(subset=['pubdate']) df['year'] = df['pubdate'].dt.year df.to_csv('swiss_ai_discourse_articles_de.csv', index=False) print(f"Exported {len(df):,} articles")

4
Analysis
LLM topic extraction & classification
Two Jupyter notebooks power the analytical layer: initial_data_analysis.ipynb produces corpus statistics and distributions; the topic extraction pipeline runs Llama-3.1-8B via a vLLM server on a UZH GPU cluster. Articles are classified into custom topic categories (e.g. Regulation, Economy, Security) or summarised.
# 1. Start vLLM server (in a tmux session) python -m vllm.entrypoints.openai.api_server \ --model unsloth/Meta-Llama-3.1-8B-Instruct-bnb-4bit \ --served-model-name llama \ --enable-lora \ --max-model-len 8192 \ --port 8000 # 2. Run classification pipeline python -m llm_module.run \ --input_file data/cleaned.csv \ --output_file topics.json \ --categories "Regulation,Economy,Security,Society" \ --mode all \ --sample 500

Serving
Flask API + this viewer
A lightweight Flask app (app.py) exposes the processed CSV as a REST API with endpoints for full-text search, source filtering, and year-range queries. This frontend calls those endpoints from the browser.
