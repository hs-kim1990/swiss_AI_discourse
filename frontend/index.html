Methodology

Data pipeline

How 13,026 articles were extracted, filtered, and structured for analysis

This corpus was assembled to study how Swiss German-language media covered AI — from early mentions in financial press to the ChatGPT explosion. The pipeline moves from a proprietary media archive through linguistic corpus tools to a structured CSV ready for analysis.

1
Source
Swissdox archive query
The Swissdox platform (UZH) provides licensed access to Swiss press archives. Queries are written in LCP (Linguistic Corpus Platform) syntax. Articles were matched by token form — searching for AI, IA, GenAI, LLM, Chatbot in any segment, with article-level metadata extracted.
LCP / CatchPhrase

Export
Result processing & export
Query results arrive as TSV/JSON from the LCP API. The export processor notebook normalises encoding, deduplicates articles, and coerces date formats to ISO 8601.
